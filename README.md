# Problem Descriptions

---

## Problem-1  
**File:** `Problem-1.py`

Create a calculator using a class that performs:
- Addition  
- Subtraction  
- Multiplication  
- Division  

**Inputs:**  
- `a`: double  
- `b`: double  
- `operation`: string (supports both names and symbols)

---

## Problem-2  
**File:** `Problem-2.py`

Given an integer `a`, generate the first `a` odd numbers.

**Example:**  
Input: `4` → Output: `1, 3, 5, 7`

---

## Problem-3  
**File:** `Problem-3.py`

Given an integer `a`:
- If `a` is **odd**, print first `a` odd numbers  
- If `a` is **even**, print first `a−1` odd numbers  

**Example:**  
Input: `6` → Output: `1, 3, 5, 7, 9`

---

## Problem-4  
**File:** `Problem-4.py`

Given a list of numbers (user input), count how many of them are multiples of the numbers **1 to 9**.

**Example:**  
Input:  
`1,2,8,9,12,46,76,82,15,20,30`

Output:
`{1: 11, 2: 8, 3: 4, 4: 4, 5: 3, 6: 2, 7: 0, 8: 1, 9: 1}`
